# Changelogs are for humans, git log is for machines

Note: `notes/changelog-discipline.md` — one of the debugging notes in this repository.

- Group entries as Added/Changed/Fixed/Removed; dates and versions at the top.
- 'Various fixes' is not an entry; name the user-visible behavior that changed.
- Generate a draft from commits, then edit by hand — automation gathers, humans curate.
- Breaking changes get a migration snippet, not just a warning.

Written while the failure was fresh; the pattern outlives the project.

Related: see `notes/ten-pr-lessons.md` for the meta-lessons.

# An error message is a UX surface

Note: `notes/error-message-quality.md` — one of the debugging notes in this repository.

- Say what failed, why, and the next action; 'invalid input' fails all three.
- Include the offending value (redacted), the expected shape, and a doc link.
- Error codes belong in machine-readable fields, not buried in prose.
- Collect your top ten errors quarterly and rewrite them; they are your support docs.

Written while the failure was fresh; the pattern outlives the project.

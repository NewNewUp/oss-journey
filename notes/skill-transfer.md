# The best documentation of a fix is the fix's test

Note: `notes/skill-transfer.md` — one of the debugging notes in this repository.

- A regression test explains the bug in the language of behavior; prose fades, CI runs forever.
- Link the test from the issue before closing it; the trail from symptom to guard stays clickable.
- Notes like this repository are the second line of defense: patterns outlive projects.
- Write the note while the failure is fresh; next quarter the details pay rent.

Written while the failure was fresh; the pattern outlives the project.

# README quickstart: five commands or people leave

Note: `notes/readme-quickstart.md` — one of the debugging notes in this repository.

- If the first command a newcomer runs fails, they close the tab — test the quickstart in CI.
- Order is prerequisites → install → one runnable command → expected output.
- Show the expected output; 'it works' is unverifiable for a stranger.
- Keep badges below the fold; they are not instructions.

Written while the failure was fresh; the pattern outlives the project.
